# Android 深色 / 浅色主题设计

## 已确认范围

设置 → 通用增加主题选择（深色、浅色），默认深色，立即生效并持久化。
首页、设置及子页面、弹窗、聊天、会议工具栏、宫格和视频画布统一适配。
摄像头与共享内容不变色；视频上的可读性遮罩和状态语义颜色保留。
主题变化不得重挂载会议或重建音视频轨道。

## 技术方向

使用现有 Redux 设置持久化保存主题，新增主题上下文和语义化浅色配色。
将静态样式转换为按当前主题解析的样式，组件通过上下文订阅变化。
导航、系统栏、基础控件和原生视频背景同步适配，避免只改 Provider。
不引入全局反色，不重载应用，不修改媒体像素。

## 验证

测试配色、默认值、持久化和样式解析；执行原生 TypeScript 检查与 Release 构建。
连接设备验证两种主题、重启恢复、首页与设置，以及能够进入的会议场景。
共享屏幕/多人会议如缺少第二设备或可用会议服务，明确记录验证限制。
